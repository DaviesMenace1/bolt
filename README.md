# Revamp UG - Luxury Interior Design Site

Full-stack luxury interior design website with CMS admin dashboard and client portal.

## Tech Stack
- React 19 + TypeScript + Vite
- Supabase (database, auth, edge functions)
- Shadcn UI + Tailwind CSS
- React Router

## Structure
- `/src/pages` - Public marketing pages
- `/src/pages/admin` - Admin CMS dashboard
- `/src/lib` - Auth, data, Supabase client
- `/supabase/migrations` - Database schema migrations with RLS policies
